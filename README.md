# Bienvenido a Data Development Center (DDC) 🚀

Transformando datos en decisiones. Somos una agencia especializada en el desarrollo de soluciones analíticas, automatización de procesos y creación de aplicaciones de gestión a medida.

---

## 🏢 Sobre Nosotros
Diseñamos arquitecturas de datos y ecosistemas digitales que resuelven fricciones operativas reales. Nuestro enfoque se centra en construir infraestructura escalable e interfaces intuitivas que permitan a los negocios operar de manera más inteligente. 📍 Base de operaciones: Puebla, México.

## 🛠 Tech Stack
Nuestra infraestructura y desarrollo se apoyan en las siguientes herramientas para ofrecer soluciones robustas:

| Área | Herramientas Principales |
| :--- | :--- |
| **Desarrollo de Apps & Automatización** | Google AppSheet, Google Apps Script |
| **Análisis de Datos & Visualización** | Python (Pandas, Plotly), Looker Studio |
| **Bases de Datos** | PostgreSQL, Supabase, MySQL, SQLite |
| **Ecosistema & Gestión Corporativa** | Google Workspace, Google Sheets, GitHub |
